# 휴대폰 시뮬레이션 웹사이트

## 실행
- `index.html`, `style.css`, `script.js` 세 파일을 같은 폴더에 둡니다.
- `index.html`을 브라우저에서 열면 작동합니다.
- GitHub Pages에 올릴 때는 세 파일을 저장소 루트에 업로드하세요.

## 포함된 기능
- 반응형 iPhone 스타일 홈 화면
- 메시지 대화 열람 및 가상 메시지 전송
- 사진첩 항목과 상세 설명
- 메모 생성/편집/브라우저 저장
- 가상 통화 기록과 전화 화면
- 기록 앱, 설정 진단
- 기록을 확인하면 열리는 숨겨진 앱
- 숨겨진 앱 접근 코드: `0217`
- 브라우저 localStorage 저장, 데이터 초기화 버튼

## 알아둘 점
- 통화와 문자 메시지는 실제 전화번호로 연결되지 않습니다.
- 데이터는 현재 브라우저에만 저장됩니다. 다른 기기와 공유하거나 여러 이용자가 같은 데이터를 보려면 서버/데이터베이스가 필요합니다.
- 실제 iOS 운영체제 자체가 아니라, iOS에서 영감을 받은 웹 시뮬레이션입니다.
